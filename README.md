# 🍳 Cooking App – Full Stack Recipe Platform

A full-stack web application built with **Angular** and **Node.js** that provides users with an interactive platform to explore, manage, and organize cooking recipes.

## 🚀 Overview

Cooking App is designed to make discovering and managing recipes easier through a user-friendly interface and a structured backend architecture. The application connects an Angular frontend with a Node.js RESTful API to handle application data and business logic.

## 🛠️ Tech Stack

### Frontend
- Angular
- TypeScript
- HTML5
- CSS3
- Bootstrap (if used)

### Backend
- Node.js
- Express.js
- MongoDB (if used)
- Mongoose (if used)
- RESTful APIs

## ✨ Key Features

- Browse and explore cooking recipes.
- View detailed recipe information.
- Organize and manage recipes.
- Responsive and user-friendly interface.
- Frontend and backend integration through RESTful APIs.

## 🏗️ Project Architecture

The application follows a client-server architecture:

- **Frontend:** Angular handles the user interface and application interactions.
- **Backend:** Node.js and Express.js handle API requests and business logic.
- **Database:** Stores application data and recipe information.

## ⚙️ Installation & Setup

### Prerequisites
- Node.js
- npm
- Angular CLI
- MongoDB (if applicable)

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
cd cooking-app
```

### 2. Backend Setup

```bash
cd Backend
npm install
```

Create a `.env` file and configure your environment variables:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
```

Start the backend:

```bash
npm run dev
```

### 3. Frontend Setup

Open another terminal:

```bash
cd Frontend
npm install
ng serve
```

Open your browser at:

```text
http://localhost:4200
```
